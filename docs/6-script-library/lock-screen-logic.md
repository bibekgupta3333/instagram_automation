# Lock Screen Logic — 20 evergreen script treatments

Active brand slug: `lock-screen-logic`. Original editorial treatments for an adult US audience, not complete narration or verified production scripts. Each standard episode is 16:9, 5–9 minutes; each independent Short is 25–60 seconds. Timings are editorial targets, to be rehearsed. The five structures are predict-and-demonstrate, reverse mystery, equal-assumption comparison, object journey, and constraint ladder. Broad retention principles—clear premise, visual proof, earned payoff—inform these original stories; no creator's voice, scenes or packaging are imitated. Reach and copyright outcomes are not guaranteed.

Production boundaries: defensive cybersecurity and privacy only, using owned devices and controlled demo accounts with synthetic data. No offensive procedures, credential attacks, fabricated incident footage, fake warnings, fearbait or security guarantees. Every experiment below is **proposed and unperformed**; conditional outcomes must become recorded observations before factual narration. Record software/device versions and recheck guidance before shooting. No real-person data, borrowed screenshots, logos or famous faces. Use original diagrams and original recordings; remove incidental third-party content. Preserve author/project files and a per-episode asset manifest with licences, permissions and dates. Recordings do not automatically clear interface rights. Research sources supply facts, not reusable artwork. Default to original sound or silence. AI image prompts require **no text**; every label, including thumbnail words, is added afterward with ffmpeg/ASS or manual editing. Thumbnails below each have one focal subject and 0–3 overlay words per option. No copied thumbnails.

Manual production is required for screen recordings, moving diagrams, comparison boards and precise compositing: the current renderer cannot automatically make all these graphics. Keep the faceless black/green/amber brand palette; use amber for distinctions, not simulated emergency alerts. No publishing or approval is authorized by these plans.
